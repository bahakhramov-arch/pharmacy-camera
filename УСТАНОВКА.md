# Перенос учёта на рабочий ноутбук (Dell, i5-10210U)

## 1. Подготовить ноутбук
- Подключить к зарядке и держать на ней постоянно.
- Электропитание: «Параметры → Система → Питание» — режим «Максимальная производительность»,
  «Переводить в спящий режим» — **Никогда** (и от сети, и от батареи).
- Крышку: «Панель управления → Электропитание → Действие при закрытии крышки» — **Действие не требуется**.
- Подключить к той же сети, что и регистратор (192.168.1.99).

## 2. Установить Python
- Скачать Python 3.13 с python.org, при установке поставить галочку **Add python.exe to PATH**.

## 3. Скачать программу и перенести личные файлы
Установить Git (git-scm.com), затем в «Командной строке»:
```
cd C:\
git clone https://github.com/bahakhramov-arch/pharmacy-camera.git camera
cd camera
```
Репозиторий приватный: при первом `git clone` откроется окно входа в GitHub — войти как
`bahakhramov-arch` (через браузер).
В git **нет** секретов и личных данных — их перенести со старого ноутбука флешкой в `C:\camera`:
- `secrets.env` — токен бота, пароль регистратора (или заполнить по образцу `secrets.env.example`);
- папку `photos\` — фото сотрудников;
- `events.csv`, `visitors.csv`, `last_seen.json` — если нужна история (без них учёт начнётся с нуля).

Модели (`*.onnx`) скачаются сами при первом запуске (~95 МБ, нужен интернет).
Обновить программу потом: `git pull` в папке `C:\camera` и перезапустить `start.bat`.

## 4. Поставить библиотеки
Открыть «Командную строку» в папке и выполнить:
```
pip install -r requirements.txt
```

## 5. Проверить
- **На старом ноутбуке программу закрыть** — бот Telegram работает только в одном экземпляре.
- Двойной клик по `start.bat`. Должны открыться окна камер и прийти сообщение
  «Система учёта запущена» в Telegram.
- В окне `Kamera 1` смотреть на `door fps`: нормально 4–5. Если меньше 3 — закрыть лишние программы.
- Пройти через дверь туда и обратно — счётчик `in / out` должен прибавиться.
- Если линия двери съехала: закрыть программу, `python door_setup.py`, поставить заново.

## 6. Автозапуск
Двойной клик по `autostart.bat` — после перезагрузки учёт запустится сам через минуту
после входа в Windows. Windows должен входить в учётную запись без пароля
или пароль нужно ввести после перезагрузки.

## Как остановить
Закрыть чёрное окно `start.bat` (кнопка Q в окне камеры только перезапускает программу
через 10 секунд). Журнал работы — `logs\run.log`.

## Сайт отчётов
Открывается с любого компьютера в той же сети: `http://<IP ноутбука>:8080`
(адрес пишется в сообщении о запуске в Telegram). Отдельно запускать `web_reports.py` не нужно.
