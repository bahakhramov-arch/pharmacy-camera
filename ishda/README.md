# Ishda AI

Новая система учёта сотрудников (вместо старой «не видно 60 минут = ушёл»).

- `tracker.py` - слежение за фигурами между кадрами (упрощённый ByteTrack)
- `identity.py` - имя трека по голосованию всех его лиц
- `pipeline.py` - камера: люди в зоне прилавка + трекер + лица
- `replay.py` - прогон по записи с регистратора для проверки

Статус: прототип, проверяется на записях Антея.
